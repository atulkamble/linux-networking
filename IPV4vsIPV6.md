# IPv4 vs IPv6 — Difference Chart (Points to Remember)

| Feature                  | IPv4                        | IPv6                           |
| ------------------------ | --------------------------- | ------------------------------ |
| Full Form                | Internet Protocol Version 4 | Internet Protocol Version 6    |
| Address Size             | 32-bit                      | 128-bit                        |
| Address Format           | Decimal                     | Hexadecimal                    |
| Example                  | 192.168.1.1                 | 2001:0db8:85a3::8a2e:0370:7334 |
| Total Addresses          | ~4.3 Billion                | ~340 Undecillion               |
| Header Size              | Variable (20–60 bytes)      | Fixed (40 bytes)               |
| Configuration            | Manual / DHCP               | SLAAC / DHCPv6                 |
| Security                 | Optional IPSec              | Built-in IPSec Support         |
| NAT Requirement          | Commonly Used               | Not Required                   |
| Broadcast Support        | Yes                         | No                             |
| Multicast Support        | Limited                     | Better Support                 |
| Anycast Support          | No                          | Yes                            |
| Speed & Routing          | Slower Routing              | Faster & Efficient Routing     |
| Address Exhaustion       | Limited addresses           | Huge address space             |
| Fragmentation            | By sender and routers       | Only by sender                 |
| Checksum Field           | Present                     | Removed                        |
| Mobile Support           | Less Efficient              | Better Mobile Support          |
| QoS (Quality of Service) | Less Efficient              | Improved with Flow Label       |
| Compatibility            | Widely Used                 | Modern Networks & Cloud        |

---

# Quick Points to Remember

## IPv4

* 32-bit addressing

* Uses decimal numbers

* Supports ~4.3 billion IPs

* Requires NAT due to limited IPs

* Example:

  192.168.1.1

* Common in older/current networks

---

## IPv6

* 128-bit addressing

* Uses hexadecimal values

* Massive address space

* No NAT required

* Better security and routing

* Example:

  2001:0db8:85a3::8a2e:0370:7334

* Used in modern cloud, IoT, and large-scale networks

---

# Interview One-Liner

> IPv4 uses 32-bit addressing with limited IP space, while IPv6 uses 128-bit addressing providing a massive number of IP addresses with improved security and routing efficiency.
